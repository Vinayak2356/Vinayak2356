## 🎯 Current Focus

- 🧩 **Application architecture** — organising code so it stays understandable as a project grows.
- ⚡ **Frontend performance** — keeping interfaces lightweight and responsive.
- 🔐 **Backend foundations** — exploring validation, authentication, and reliable APIs.
- ☁️ **Deployment workflows** — learning more about containers and automation.
- 🤝 **Open-source collaboration** — finding useful ways to learn and contribute.

<details>
<summary><strong>🧠 How I Approach a Project</strong></summary>

<br />

**01 · Understand the need**  
Start with the people using the product and the problem they want to solve.

**02 · Find the simplest useful version**  
Choose a clear scope and build the essential experience first.

**03 · Build across the stack**  
Connect the interface, application logic, and data.

**04 · Check the experience**  
Review small screens, loading states, errors, and important interactions.

**05 · Learn and improve**  
Use feedback to make the next version better.

</details>

<br />

<details>
<summary><strong>⚡ A Little Developer Personality</strong></summary>

<br />

- A clean interface makes me happy.
- A readable function makes future me happy.
- A mysterious bug usually means it's time to slow down.
- Small improvements add up.
- There is always something new worth learning.

> First, make it useful. Then, make it clearer.

</details>
